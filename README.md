## Regional Australia: who represents you (`/au`)
Pick a state and postcode, land on the main council's page: sub-postcodes at the top, then council, federal MP, senators, state MP, Premier and PM, each with its source.
Regional only (capital-city postcodes are left out). Data lives in `src/au-data.json`, built by `tools/build-au.py` from AEC locality data (2025 boundaries), ABS LGA and state electorate boundaries, and fact-checked member lists (checked 17 Oct 2026).
Refresh after any election or by-election: next up is Victoria, 28 Nov 2026.
